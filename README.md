# E-Learning Killer (Chrome拡張機能)

ブラウザ上の選択式クイズ・eラーニング（ラジオボタン、チェックボックス複数選択、選択肢ボタン、ドロップダウン、SCORM等のiframe内コンテンツ）をAIで解析し、**解答選択 → 送信 → 次の問題へ** を全自動でループ実行するChrome拡張機能です。

## 主な特徴
- **DeepSeek標準対応 & マルチAPI対応**:
  - デフォルトで **DeepSeek API** (`deepseek-chat` / `deepseek-reasoner`) に最適化済み
  - **OpenAI / Google Gemini / Anthropic Claude / OpenRouter / Groq / Ollama (ローカルLLM) / 任意のOpenAI互換API** にワンタッチ切替可能（プロバイダごとにAPIキーを個別記憶）
- **全自動ループ & 1問実行の両対応**:
  - 解答選択 → 「解答する / 送信」 → 解説画面の「次へ / 次の問題へ」 → 完了画面での自動停止まで対応
  - 同じ画面から進まない場合の無限ループ自動防止機能つき
- **iframe / SCORM 対応**:
  - 企業・大学のLMSで多い `iframe` 内の問題フレームを自動検出して操作
- **ページ右下フローティングパネル (Shadow DOM)**:
  - ポップアップを開かなくても画面右下のミニパネルやショートカットキーからワンクリックで開始・停止可能

---

## 導入手順（1分で完了）

1. Chrome（または Edge / Brave 等のChromium系ブラウザ）で `chrome://extensions/` を開く
2. 右上の **「デベロッパー モード」** を **ON** にする
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、このフォルダ (`c:\Users\standard\AI\e-learning-killer`) を選択する
4. ツールバーの拡張機能アイコンから **E-Learning Killer** を開き、**「API設定」** タブに DeepSeek（または使いたいサービス）の **API Key** を入力して **「🔌 接続テスト」** を押す

> **ローカルの `demo_quiz.html` で動作テストする場合**:
> `chrome://extensions/` の E-Learning Killer「詳細」から **「ファイルの URL へのアクセスを許可する」** をONにして、`demo_quiz.html` をブラウザで開いて「▶ 全自動でしばく」を押すと全3問を自動で解き切る様子を確認できます。

---

## 操作方法・ショートカット

- **ページ右下のミニパネル** または **拡張機能ポップアップ** から操作:
  - **▶ 全自動開始 (`Alt + Shift + S`)**: 問題がなくなる（完了画面になる）まで自動で解き続けます。もう一度押すと即停止します。
  - **⚡ 1問解く (`Alt + Shift + Q`)**: 今表示されている1問だけ解答します。
- **動作・詳細設定タブ**:
  - 問題間の待機時間（ミリ秒）や選択→送信間隔の調整
  - 右下フローティングパネルの表示ON/OFF（画面をスッキリさせたい場合はOFFにしてショートカットのみで操作可能）
  - 画面キャプチャ添付（GPT-4o / Gemini / Claude 等のVision対応モデルで図表問題を読む場合のみON）
  - 追加プロンプト（例：「情報セキュリティ研修です」「社内規定に基づき最も安全側の選択肢を選んでください」など）
